# FreshFood Customer Web

Technology: React. Structure only; React dependencies are declared in package.json.

- src/Pages: future customer-facing page components.
- src/CallService: future API-call integration classes/modules.
- public: reserved static assets.
- tests: reserved test sources.

No page, HTML host, React entry point, API call or feature has been implemented.
A bundler, routing library, styling framework and state library have not been
selected. There are intentionally no start/build/test scripts yet.
